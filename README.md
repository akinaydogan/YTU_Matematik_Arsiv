# YTÜ Matematik Bölümü Arşivi

Yıldız Teknik Üniversitesi Matematik Bölümü öğrencileri için çıkmış sorular, çalışma soruları ve ders kitaplarının toplandığı açık kaynak arşiv.

> Bu proje resmi bir üniversite kaynağı değildir; öğrencilerin birbirine katkısıyla oluşur. Hatalı veya eksik bir şey görürseniz Issue açabilir ya da Pull Request gönderebilirsiniz.

## Klasör Yapısı

Dersler dönemlere göre ayrılmıştır. `1-1` birinci sınıf güz, `1-2` birinci sınıf bahar dönemi anlamına gelir.

```
├── 1-1/
│   └── Ders Adı/
│       ├── Çıkmış Sorular/
│       ├── Çalışma Soruları/
│       └── Kitaplar/
├── 1-2/
├── ...
├── 4-2/
├── readme_olustur/      # Ders listesini otomatik üreten script
├── README.md
├── .gitignore
└── .gitattributes
```

## İçerik Türleri

| Klasör | İçerik |
| --- | --- |
| Çıkmış Sorular | Vize, final, bütünleme ve kısa sınav soruları (mümkünse çözümleriyle) |
| Çalışma Soruları | Ders sorusu setleri, alıştırmalar, ödevler |
| Kitaplar | Dersin kaynak kitapları ve ders notları (PDF) |

## Dosya Adlandırma

- Çıkmış sorular: `2024-Güz-Vize.pdf`, `2023-Bahar-Final-Çözümlü.pdf`
- Çalışma soruları: `Hafta-05-Alıştırmalar.pdf`
- Kitaplar: `Yazar-Kitap-Adı.pdf`

## Nasıl Katkı Yapılır?

1. Repoyu fork'layın.
2. İlgili dönem ve ders klasörüne dosyanızı ekleyin.
3. Dosya adlandırma kurallarına uyun.
4. `python readme_olustur/readme_olustur.py` komutunu çalıştırarak ders listesini güncelleyin.
5. Pull Request açın.

## Telif Hakkı Uyarısı

Kitap PDF'lerinin telif hakkı yazarlarına ve yayınevlerine aittir. Bir hak sahibi kaldırılmasını isterse ilgili dosya silinir. Yalnızca paylaşımına izin verilen veya serbest lisanslı kaynakları eklemeye özen gösterin.
